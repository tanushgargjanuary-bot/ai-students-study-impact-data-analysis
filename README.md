# AI Impact on Students — Data Analysis Project

## Overview

This project explores how AI usage relates to student academic performance, study habits, burnout risk, and subscription behavior.

The analysis was performed using Python and Pandas on a dataset containing 50,000 student records.

The goal was not to build a machine learning model, but to practice a complete data analysis workflow:

- Dataset inspection
- Data quality validation
- Exploratory Data Analysis (EDA)
- Correlation analysis
- Group-based analysis
- Cross-tabulation analysis
- Finding generation
- Report writing

## Dataset Overview

The dataset contains student-related variables including:

- AI usage hours
- Prompt engineering skill
- Tool diversity
- Paid subscription status
- Traditional study hours
- Institutional policy
- Burnout risk
- Skill retention
- Semester GPA

The objective was to investigate whether AI-related behaviors appear associated with academic outcomes.

---

## Key Questions Explored

- Does AI usage relate to GPA?
- Does traditional study time relate to GPA?
- How does burnout relate to AI usage?
- Do institutional AI policies influence behavior?
- Are paid AI subscriptions associated with burnout?
- Which factors appear most associated with academic outcomes?

---

## Main Findings

- Traditional study time showed a weak positive relationship with GPA.
- AI usage time showed little relationship with GPA.
- Students with high burnout reported substantially higher AI usage.
- Students with high burnout were more likely to purchase AI subscriptions.
- Tool diversity showed little relationship with burnout.
- Most AI-related variables showed weak relationships with GPA.
